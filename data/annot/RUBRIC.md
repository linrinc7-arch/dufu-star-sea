# 杜诗定年·定地点·大白话译文 —— 作业规范

你要为分配到的每一首诗产出四个字段：写作时间 `y`、写作地点 `w`、**依据** `d`、大白话译文 `t`，
可选「诗中之意」`m` 与判定性质 `c`（考据 / 推定）。

## 一、铁律（违反即作废）

1. **不许编造**具体事件、人名、官职、年份。诗里没有的线索，不要写成史实。
2. 不能确指年代时，写区间并标 `"c":"推定"`，例如 `"约 754—755 年（天宝末，居长安）"`；能确指（有明确地名、事件、赠答对象）标 `"c":"考据"`。
3. `y` 里必须含四位年份或「约 7XX」，不许只写「早年」「晚年」。
4. `w` 要落到具体地名 + 今地名，例如「夔州（今重庆奉节）」「潭州（今湖南长沙）」。实在判不出写「行迹不详（可能作于…一带）」。
5. `d` 必须**引用诗中原词**（不超过 40 字），说明凭什么这样定年定地。不许写「据学界通行说法」这种空话。
6. 译文用**现代汉语口语**，像老师当面讲给学生听：短句、说人话，不用「之、乎、者、也、焉、矣」。名句可留原句，但后面要用白话解释。
7. 译文长度 **≥ 原文 1.2 倍**（校验脚本会卡）。诗中出现的每个人名、地名、典故、官名、器物，都要在译文里带一句解释，不要跳过。
8. 只输出 JSON 文件，不要在对话里贴全文。

地理词就是最硬的证据：出现「秦州/同谷」→ 759；「成都/草堂/浣花」→ 760—765；「夔州/白帝/瞿塘/滟滪」→ 766—768；「岳阳/洞庭/潭州/衡州/潇湘」→ 768—770；「长安/曲江/渼陂」→ 746—755；「兖州/泰山/齐赵」→ 736—740。

**注意陷阱**：同一个词在不同诗里指的不是一回事。例如「白帝」在华山诗里指西岳大帝，不是夔州白帝城；「望岳」三首分咏泰山、华山、衡山，题名不能当分期证据。

## 三、译文风格示例

原诗（华山《望岳》，56 字）：
> 西岳崚嶒竦处尊，诸峰罗立如儿孙。安得仙人九节杖，拄到玉女洗头盆。车箱入谷无归路，箭栝通天有一门。稍待西风凉冷后，高寻白帝问真源。

合格译文：
> 西岳华山高峻层叠，耸在那儿独自尊贵，周围的山峰排成一片站着，像它的儿孙。哪里能弄到仙人那根九节杖，好让我一直拄到玉女洗头盆的边上？车箱谷一走进去就没有回头的路；箭栝峰直通天上，只开着一道门。等秋风起来、天转凉以后，我再上山去寻白帝，问一问道的源头。

不合格：只把原句换成同义文言（「西岳高峻，众峰罗立」）；或漏掉「车箱谷」「箭栝」「玉女洗头盆」这些专名不解释。

## 四、输出格式

写到 `data/annot/parts/pNNN.json`（NNN 与输入批次号一致）：

```json
{"batch": 1, "poems": [
  {"id": 539, "y": "乾元元年（758）秋，贬华州司功参军赴任途中",
   "w": "华州（今陕西华阴）一带，望西岳华山而作", "c": "考据",
   "d": "「西岳崚嶒」「车箱入谷」「箭栝通天」皆华山实景；758 年六月贬华州。",
   "t": "西岳华山高峻层叠……问一问道的源头。",
   "m": "写华山不写高，只写「尊」：一峰竦立，众峰如儿孙。"}
]}
```

## 五、自检

写完运行（这台机器的 python 不在 PATH 里，用下面这个绝对路径）：
```
"C:\Users\Admin（无密码）\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" work/check_part.py data/annot/parts/pNNN.json
```
有 ERR 就改到全过；脚本会检查 id 是否存在、字段是否齐、译文是否够长、时间是否带年份。
