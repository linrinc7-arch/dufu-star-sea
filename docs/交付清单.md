## 二、作品一句话

本项目收录的一千四百六十八首杜甫诗，被放成一片可以走进去的星海：球心是《望岳》——他二十四岁写的、现存最早的作品之一；每一颗星是一首诗，离球心的远近就是那首诗离起点的远近；星与星之间的线，只在「共享意象」且「视野内相邻」时才连；而银河带里那些暗到几乎看不见的光点，是机器用他自己的字拼出来的两万首伪诗——真诗是亮的，可能的诗是暗的，但都在天上。

## 四、怎么复核（三条即可）

1. **统计类**：`dufu_poems.csv` 筛 `form` 列 = 五言律诗 / 七言律诗，共 830 行（占 56.5%）——「五律七律占其诗过半」由此而来。
2. **意象类**：`imagery_counts.csv` 按 `word` 聚合，`word='愁'` 求和 = 176、`'病'` = 162、`'兵'` = 115、`'骨'` = 85。
3. **空间类**：`starfield_coords.csv` 的 x/y/z 就是网页里星点的坐标，两点欧氏距离即网页上的远近。

## 六、数据来源与声明

- 语料：开源《全唐诗》数字文本（57,607 首）；繁简转换 OpenCC + 自建异体字表；正文未经人工校勘的条目已在作品内逐首注明「可能仍带录入讹字，引用请核纸本」。
- 注释（字注 / 今译 / 串讲 / 赏析 / 背景 / 名句）：本项目撰写，系年与本事不确定者标「推定」。
- 配图：按诗题与意象生成的水墨风插图，**非古画原件**，作品内每处图版均如此标注。
- 天幕：不依赖贴图，由 20,000 首机器伪诗与噪音场程序化生成。
