# 诗云 · 白噪音

## 这是什么

一层机器写的伪诗，作为作品里真诗的对照物。它只用杜甫自己的字：
1,468 首诗、10.5 万字。

## 怎么生成

把全诗切成 15,361 句五言、3,839 句七言，分别统计三样东西：
每个字出现多少次、哪些字两两相邻、五言与七言各自的句尾用字。

生成时固定随机种子（20261020），每句锁死 5 字或 7 字。
每个字由它前面的两个字决定（二阶马尔可夫链）；上下文太罕见时，
向下退到双字与单字频率——正是这层退让，让整句不会被抄回原诗。
每句用真实的句首双字起、真实的句尾双字收，所以乍看像诗；
但四句之间毫无连贯，机器也从不检查哪两句是否同韵。

## 得到的数字

| | |
|---|---|
| 规模 | 20,000 首 × 4 句 = 80,000 行，43.2 万字 |
| 用字 | 4,157 个（源诗 4,181 个） |
| 与杜甫原句完全相同 | 6 行（0.0075%） |
| 含四字连续重合 | 8,151 行（10.19%）——拼得出半句，拼不出一整句 |
| 第 2、4 句末字偶然相同 | 31 首（0.15%）。这不是押韵，只是复读了句尾统计 |
| 组合空间下限 | 4,181²⁰ ≈ 2.7×10⁷² 首 |

两万首只占这个下限的十的负六十九次方。而真正的"诗云"还要算上七言、
杂言与更长的篇制，只会更大。

## 它想说的

它不是乱码。乱码一眼就假；它每一处都合乎统计——也正因为处处合乎统计，
凑近去读时，意义才整块塌下去。

> 机器可以穷尽所有组合，却判断不出哪一首是好诗。

所以这面墙不需要被读完。它只是让人先看见"多"，
再回头去看那一千四百六十八首里，为什么偏偏是《登高》。
