# 经典文本关联说明

（正文 420 字）

杜甫存诗 1,468 首。本作把它们放进一片由用词与意象决定的语义空间，使“沉郁顿挫”从形容词变成可被看见的位置与密度。

## 一、杜甫：从几首诗看沉郁

《登高》的区别性意象是“浊酒”“酒杯”“落木”“鬓”——“万里悲秋常作客，百年多病独登台”十四个字里，空间、时间、身世、身体四重维度同时压来。《春望》落在“烽火”“白头”，与“国破山河在”相应。《北征》落在“白骨”“衾”“民”，见其以赋为诗的路数。统计口径上，“病”162 次、“愁”176 次、“兵”115 次、“骨”85 次；这些诗在星海里聚成偏暗偏密的区域。五律与七律合计 830 首，占 56.5%，是“顿挫”的收束。

## 二、杜甫与李白

交游面板收杜甫赠李白诗 11 首，边宽即赠诗数；二人 744 年遇于洛阳，同游梁宋、齐鲁，别后十五年只在诗里相见。作品以严羽《沧浪诗话》“子美不能为太白之飘逸，太白不能为子美之沉郁”为题眼——飘逸与沉郁不是褒贬，是两种面对世界的姿态。作品没有停在引文：点“在星海中查看写给李白的 11 首”，天球只亮这十一颗。它们散在天象时序、器物、动物、植物、身体生命、宗教哲理、人伦交往七类，两两相距的中位数是 0.90，与全图任意两点相当；而每一颗自己又埋在密集的星群里，最近邻只有 0.09。密度上，11 首占全图的 0.75%。于是“沉郁”与“飘逸”有了可比的形式：一个是把一生写成一个密实的球，一个是同一个人散在各处，始终没有自己的星区。
