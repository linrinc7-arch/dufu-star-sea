# 杜诗星海 · The Star Sea of Du Fu

一千四百六十八首杜甫诗，放进一片由代码算出来的星海。

---

## 一、要交付的东西在哪

```
交付/
  杜诗星海.html              ← 主件：单文件，双击即开，断网可用（3.4 MB）
  杜诗星海_全图版/            ← 作品 + 1468 幅外置图库（保持目录结构，双击 index.html）
  使用说明.txt               ← 给使用者的操作说明
  技术方法说明.docx           ← 数据与算法说明
  经典文本关联说明.docx        ← 文本关联说明
  数据/                      ← 语料与坐标的 CSV，及 README
```

交付只需要上面这个目录，其余都是工程文件。

## 二、工程文件（改代码时才用）

```
web/            源码：index.html（全部逻辑约 5000 行）+ 数据脚本 + art/
pipeline/       构建与检查：04_bundle.py（打包单文件）、08_smoke.py（冒烟）…
docs/           交付文档的源文件
迭代/           每一轮的改动记录（第01…108轮）+ 截图 + 逆向报告 + 评审记录
data/           中间数据（语料、特征、坐标）
项目记录.md      技术决策的完整来历
DESIGN.md       视觉与交互设计说明
```

## 三、改了代码怎么重新打包

```bash
# 1) 从源码构建单文件（输出到根目录 杜诗星海.html）
python pipeline/04_bundle.py

# 2) 复制到交付目录
cp 杜诗星海.html 交付/杜诗星海.html
cp web/index.html 交付/杜诗星海_全图版/index.html

# 3) 冒烟：headless Edge 打开单文件，点一首诗，确认诗卡出现
python pipeline/08_smoke.py
```

## 四、想回到某个历史版本

```bash
git log --oneline                # 看历史
git checkout 42af4b7 -- web/index.html   # 回到 R104（用户确认喜欢的版本）
```

另有一份不依赖 git 的物理快照：`迭代/快照/R104/`（源码 + 构建好的 html + 还原说明）。

## 五、几个关键参数在哪改

| 想改什么 | 改哪里 | 现在是 |
|---|---|---|
| 初始机位远近 | `web/index.html` 里 `cam={...dist:...}` 与 `INTRO.to` | 2.00 |
| 初始俯角 | 同上 `pitch` | −0.505（≈30°） |
| 遨游速度 | `ROAM_BASE` | 0.30（Shift ×2） |
| 拖拽灵敏度 | `var SENS=roamOn?...:...` | 遨游 0.0013 / 轨道 0.0026 |
| 星星密度 | `PCN`（可数星）、`DUSTN/DUSTR`（尘埃层） | 72000 / 560000+310000 |
| 视野限制 | `roamViewLimit()` | 远处 20°、内部放宽到 46° |
