## 文学 R11：48（+1），它说我「把 id 键修反了」

> `analysisFor()` 判的是 `p.id`，诗对象只有 `i`，所以 `id:24`/`id:22` 两条全屏永不出现；
> 卡片仍按 `ANALYSIS[p.t]`，三首望岳、两首赠李白继续共用。

确实。而且就算改成 `p.i` 也不行——运行时的 `i` 是**数组下标**，不是数据库 id。

## 改法：用首句指纹，不依赖任何 id

```js
"望岳":   {id:24, sig:"岱宗夫如何", ...}
"赠李白": {id:22, sig:"二年客东都", ...}
```

```js
if(a && a.sig && (p.L[0]||'').indexOf(a.sig)!==0) a=null;
```
