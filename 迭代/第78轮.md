# 第 78 轮 · 2026-10-21 08:10 · 系年以人工解析为准

## 冲突的根因

导出脚本 `03_export_web.py` 里写的是 `'pd': PDP[i]`——时期标签由**模型**算，
完全覆盖了诗条里人工核过的值。所以「pd 与解析年冲突 23/47」不是数据错，是**导出时把人工结论丢了**。

## 改法

```python
'pd': (src.get('pd') if src.get('pd') is not None else PDP[i])
```

再加一个脚本 `14_periods_align.py`：读解析里的年份（「767 年秋」→ 767），
按五期边界折算成期号，回写诗条的 `pd`。

| | 改前 | 改后 |
|---|---|---|
| 一（731–745） | 63 | 64 |
| 二（746–755） | 196 | 193 |
| 三（756–759） | 347 | 349 |
| 四（760–765） | 249 | 253 |
| 五（766–770） | 613 | 609 |

40 首有解析的诗，时期现在服从解析年——《春望》757 一定落在「陷贼与为官」，
《登高》767 一定落在「夔州·湖湘」。
