# 第 26 轮 · 2026-10-20 11:20

## 用户反馈

> 白噪音的意思是你做星云不是需要很多诗很多星星吗，生成白噪音组成的诗和题目做成一个新的诗。能不能不要做贴图。
> 记得白噪音星点暗一点小一点，不要抢了杜甫的诗的焦点，然后只用杜甫的诗里面出现过的字生成白噪音。

两条合起来是一句话：**天幕不该是图片，它本身就是"诗云"——九万首机器写的诗堆出来的那团云。**

## 做法

### 1. 删掉贴图

`sky.jpg`、等距圆柱重采样、按列切片的绘制，全部撤掉。
天幕不再加载任何图片，单文件也因此小了 1MB。

### 2. 诗变成星点

- 浏览器里读 `data.js` 的一千四百六十八首诗的原文，建二阶马尔可夫链（只用杜甫出现过的 4,181 个字）
- 生成 **90,000 首**：每首有题目（题目的字与词尾也从杜甫自己的题目里取）、有四句（五言/七言按真实句长分布）
- 位置：约八成落在大圆附近做高斯扩散，银心一侧更厚；再用三维值噪声做接受概率——云团和暗尘是**密度差**长出来的，不是画上去的
- 亮度与体量跟着**局部密度**走：密处连成雾，疏处只是一粒灰

### 3. 不抢杜甫

- 暗星的亮度档位 0.035—0.215，最大 1.75px；诗星核心是 255、最小 3.4px
- 暗星不参与交互，只在你把指针停上去时，按种子**现写**那一首给你看（题目 + 两句 + "机器所写 · 可读，无义"）

### 4. 数字

| 项 | 值 |
|---|---|
| 天幕里的伪诗 | 90,000 首，每首有题目与四句 |
| 生成用字 | 4,181（杜甫全部用字），无一例外 |
| 绘制方式 | TypedArray + 20 个 (亮度×颜色) 桶，一次绘制不切状态 |
| 泛光 | 0.26，让密处的点自己连成雾 |

## 结果

天幕变成一片**由诗组成的星野**：银河带在远处是雾，近看是一粒一粒能读的诗。
杜甫的一千四百六十八颗仍然最亮最大，机器写的九万首在最底下。
