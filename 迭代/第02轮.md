# 第 02 轮 · 2026-10-20 01:05

## 本轮做了什么

### 1. 关系四维（用户提案，评 8.5/10 后采纳）
- 默认关系＝**意象**（唯一由文本算出的：lift 区别性意象 + 语义最近邻）
- 时期 / 题材 / 体裁 收进卡片四个标签，点一下＝对某一维度提一次问
- 换关系时默认意象连线自动熄灭（同一屏一个金色语义）
- **线型编码关系类型**：意象实线、时期虚线、题材点线、体裁点划线

### 2. 名篇呼吸
38 首高知名度诗作：体量 ×1.92、±16% 呼吸、双层光晕、四芒星线；诗卡加金色「名篇」标。

### 3. 依据块（C2 目标）
诗卡新增：
- **词典命中**：该诗被十类意象词典命中多少处、分别是哪些词与次数
- **近邻**：《最近的三首》——可点击跳转

这让"为什么给它这个标签"变成可查的。

### 4. 不确定性标注（D2 目标）
- 卡片元信息：`≈流寓湖湘 推定`（≈ 符号 + 上标"推定"）
- 关系说明：`关系 · 推定同期（流寓湖湘）的诗共 612 首`

### 5. 架构改造：作品 + 外部图库（用户要求）
- `web/index.html` 改为双层背景回退：`art/opt/<slug>.jpg`（精选）→ `art/all/<id>.jpg`（全量）
- 交付产出两种形态：单文件版（30 幅内联，展览用）+ 全图版（外置图库，按需加载）
- 全量图库由 `pipeline/artqueue.py` 驱动多个代理并行生成，当前 62 幅

### 6. 修掉的三个真 bug
| bug | 后果 | 修法 |
|---|---|---|
| `wc` 未传入前端 | 依据显示"命中 0 处" | pts 映射补 wc |
| 加入依据块后诗卡变矮 | 竖排诗句折行成两列 | `.col{white-space:nowrap}` + 重排卡片比例 |
| 队列 stdout 走 GBK | 代理拿到的提示词乱码 | 强制 UTF-8 + 任务写入 claims/<worker>.json |
