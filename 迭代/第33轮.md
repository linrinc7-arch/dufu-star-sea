# 第 33 轮 · 2026-10-20 12:20

## 用户

> 把望岳视角删了，我想做的是类似于陀螺的宇宙中心，两边尖尖的收敛，中间宽宽的，整个宇宙围着他转，取消星云设定，然后太卡了，优化白噪音加载逻辑。

## 四件事

### 1. 删掉「望岳 / 宇宙」视角切换

底部那一排少了一组开关；对应的绑定代码整段移除，SKY 不再参与渲染。

### 2. 光锥 → 陀螺

上一版是「两头宽、中间收成一点」（沙漏），用户要的是反过来：**两头尖、中间宽**，像一枚立着转的陀螺。

半径改成 R·(1-|t|)^0.86：t=±1 时半径为 0（尖），t=0 时最宽。
轴改成竖直，于是整个宇宙绕它转时，它的轮廓保持稳定——转的是星星，不是它。

### 3. 取消星云

三级模糊缓冲（1/3、1/8、1/22 + blur/contrast）全部删掉，诗点直接画到主画布：粒是粒，不是雾。

### 4. 优化白噪音

| 之前 | 现在 |
|---|---|
| 每帧 150,000 次 fillRect 到 1/3 缓冲 | 每帧 110,000 次 fillRect 直接画主画布 |
| 每帧 3 次全屏 drawImage + 两次 blur 滤镜 | 0 次全屏拷贝、0 次滤镜 |
| 每帧 3 张缓冲画布 | 0 张 |

blur(8px) 作用在 2559×1599 上是这一套里最贵的一步，砍掉它之后帧率立刻回来。
颜色分五档亮度 × 四档色相共 20 个桶，逐桶切换状态，避免每点改 fillStyle。

## 现在的样子

一枚立着的陀螺：上尖下尖、中段最宽，通体由九万首白噪音诗堆成；
杜甫的一千四百六十八首在它外面绕着转。没有星云，也没有地平线。

## 下一步

- 陀螺的「转」目前靠相机缓慢环绕。若要它自己转，得把粒子按轴向旋转——需要预算（每帧 11 万次三角函数），可能要用极角预计算 + 增量旋转来省。
- 中段颜色偏橄榄，应该更暖一些（金 → 米白），尖端保持冷蓝。
