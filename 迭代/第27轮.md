## 做了什么

1. **下载**（git 协议被重置，改用 codeload 的 zip 包）：
   - `refs/impeccable-main/`：pbakaus/impeccable，含它自己的 DESIGN.md（Neo Kinpaku：黑漆 + 金 + 铜绿）、
     agent skill（SKILL.src.md）、CLI 与 Rust 引擎
   - `refs/awesome-design-md-main/`：VoltAgent 的 84 个真实品牌 DESIGN.md（Linear、Apple、Figma、Clay…）
2. **消化**：读完 impeccable 的 Colors / Typography / Elevation / Do & Do Not 四节，
   取出三条与我们同源的规则：
   - The Gold Carries Brand Rule（金是语义，不是装饰）→ 我们收得更狠：只编码"关系"
   - Hairline First + No Default Card Shadow（先发丝线，不先阴影）
   - Weight Inversion（h2 比 h1 重）与 Dark Type Needs Air（深底行高 1.65—1.8）
3. **落地**：新建根目录 `DESIGN.md`——颜色令牌（附 OKLCH 近似）、八级字号、
   天幕的"诗云规则"、材质、动效、Do/Do Not，以及参考项目速查表。
4. **验收**：1600×900 与 1440×900 各截一次图，版式不塌。

## 为什么放在根目录

两个项目都用 `DESIGN.md` 这个约定：把它放进项目根，任何读代码的 agent 都会先读到它。
所以我们不再把它塞进 `docs/`，而是放在最显眼的地方，并在 `项目记录.md` 里指向它。
