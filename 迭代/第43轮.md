# 第 43 轮 · 2026-10-20 15:50 · 银河系回来了

## 用户

> 怎么又变成一个球了，让你做成银河系那样。

上一轮为了「各个角度都正常」，把带内占比降到 0.38 并大量散布，结果天球又变成一颗星球的球面——
评审说「各角度正常」是对的，但用户要的是**银河系**，不是球。这两件事在球面投影下无法同时满足。

## 做法：回到盘，用三维透视看它

| 项 | 这一轮 |
|---|---|
| 布局 | 指数盘 + 两条对数螺旋臂 + 小核球（3%），盘厚随半径衰减 |
| 投影 | 三维透视（相机在盘外，从斜上方看） |
| 白噪音 | 同一枚盘里的 14,000 粒，构成旋臂与核的底光 |
| 相机 | dist 2.7 / pitch 0.34：盘斜过整个画面 |
| 可点击 | 布局后做 4 轮「轻推」，任意两颗在世界里至少隔 0.045；屏上最近邻中位数 4px → **8px**，p25 5px |

## 为什么这样点得动

1468 颗星铺满一屏，平均间距本来就只有几十像素，旋臂与核球更难。除了「推开」这一手，
还有三条兜底：悬停吸附半径 26px（取最近的一颗）、12 颗名篇常驻题名、检索框回车直达最匹配的一首。

## 用户可见的变化

- 画面重新是一枚**有两条旋臂、中心发亮的银河**，不是星点铺满的球
- 旋臂上能读到《望岳》《登高》《石壕吏》《兵车行》……
- 点任意一颗仍然开卡；核球最密的地方，点下去取最近的一颗
