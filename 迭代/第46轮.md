## 生成器（web/index.html 内，约 100 行）

| 步骤 | 做法 |
|---|---|
| 噪声 | 3D 值噪声（按球面方向采样，天然无缝、无极点撕裂） |
| 扭曲 | 两次域扭曲：卷须与丝缕 |
| 丝 | `1-|2n-1|` 取幂，得到脊状结构 |
| 尘埃 | 另一层 fbm 减去密度，挖出暗带与空洞 |
| 配色 | 密度三档：青蓝 44,126,206 → 洋红 196,48,112 → 赭金 232,152,78 |
| 色调 | `1-exp(-x)` 软肩，避免 8bit 削顶造成的色块 |
| 分辨率 | 1,024×512 逐像素算，再平滑拉到 2,048×1,024（气体本来就软） |
| 星 | 贴图里另撒 5,200 颗细星 |

## 天幕怎么贴

按 yaw 横滚、按 zoom 缩放、按 pitch 上下留边并 clamp（保证始终铺满），三块拼贴无缝。
缩放时仍是和星点同一套焦距，所以「云跟着星星一起放大」。

## 诗与白噪音

- 1,468 首诗：58% 贴银道带、42% 铺满天，彩色星点 + 十字光晕
- 24,000 粒白噪音：同样的分布当底光，带内偏暖

## 结果

整屏是深空摄影的质感：洋红电离氢的丝缕、青蓝的反射云、赭褐尘埃的空洞、满天细星，
而杜甫的一千四百六十八首是其中更亮、带光晕的那些点。全部由代码算出，断网可跑，单文件 5.98MB。
