## 2. 飞行：从「能走」到「好开」

旧的 roam（`web/index.html` 旧 3106—3326 行）只有 W/S/A/D + 空格/C + Shift×2.6，
相机没有滚转、没有速度读数单位、没有归位；退出返航用墙上时间，掉帧会跳。

| 项 | 旧 | 新 |
|---|---|---|
| 朝向 | yaw/pitch 两个角 | 加 **roll**，Q/E 滚转，角速度朝 1.35 rad/s 收敛，松手自动回正（`1-exp(-dt·0.5)`） |
| 平移 | 沿视线，A/D 只改 x/z | **右/上向量随滚转旋转**，A/D 贴着船舷走，空格/C 沿船顶走 |
| 推力 | `ease=1-exp(-dt·7.5)`（τ≈0.133s） | `1-exp(-dt/0.14)`，帧率无关；Shift×3.0；滚轮改航速 0.25—6.0 |
| 环视 | 只能拖 | 拖 + **点虚空锁鼠**（Pointer Lock），movement 0.0022 rad/px，Esc 先解鼠再谈退出 |
| 归位 | 无 | **V** 键：900ms 滑回总览机位，不退出遨游 |
| 全屏 / 隐 UI | 无 | **F** / **H**（H 收掉全部界面，只留星海与十秒的提示） |
| 退出返航 | 墙上时间，掉帧会跳 | 累计 dt，1.1s，同样走 smoothstep |
| 边界 | 球壳 3.55 硬夹 | 外 6.2 软球壳（吃掉法向速度、顺壳滑），内 0.05 不许钻进银心 |
| 读数 | `距银心 3.05 / 航速 1.00×` | `距离银心 4.11 / 航速 ×1.00 · 99 单位/秒`，等宽 tabular-nums，附键位一行 |

**验收（headless 用 `__DUFU_DEBUG.tick/roamKey` 定步长跑，不靠 rAF）**：
进入时 r=4.105；按 W 三秒 r=2.526（≈0.53 单位/秒，与 ROAM_BASE 0.55 相符）；
按 Q 0.75 秒 roll=−0.87（≈1.16 rad/s）；退出 1.1s 后 roamOn=false、r=0；
V 归位后 r=4.11 且仍在飞行模式。

## 3. 视角放小：一个数 + 两个补偿

`cam.dist` **2.9 → 3.9**（盘径从 95% 缩到 71%，四边留出呼吸位）。
只改这一个数会变暗变稀，所以同时：

- 背景点径 `(2.6/d) → (3.5/d)`（d 变大后补偿透视衰减）；
- 下限 0.55px → **0.6px**（暗星不消失）；
- 首帧/进入遨游用全量、飞行中用半分辨率重建（见 §4）。
