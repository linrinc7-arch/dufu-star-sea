# 第 80 轮 · 2026-10-21 09:10 · 一个 P0，和它带来的闸

## 事故

技术评审在测交付物时发现：**点任何一颗星都打不开诗卡**。

根因是我上一轮加「卡片校记」时，把 `renderEvidence()` 里的两行复制进了 `renderFull()`，
只复制了使用 `if(_col){...}`，没复制声明 `var _col=...`。于是 `select()` 抛 ReferenceError，
而它排在 `card.classList.add('on')` **之前**——卡片永远不出现。

这是我第二次犯同一类错：**装饰性代码把主流程带走了**。

## 修复

- 在 `renderFull()` 开头补 `var _col=(window.COLLATION||{})[p.t];`
- 删掉 `renderEvidence()` 里那次重复声明
- 实测：点星 → `card=true`，标题「登高」，依据 73 字

## 这次加了一道闸

新增 `pipeline/08_smoke.py`：交付前在 headless 里打开单文件、点一首《登高》，
**卡没出现就让打包失败**。已经接进 `07_package.py`，每次构建都跑。

```
冒烟： SMOKE ok card=true title=登高名篇 evd=73
```

这类「点星没反应」的回归，以后不会再有第二次交付出去的机会。
