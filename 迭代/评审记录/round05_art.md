## 四、还剩三条最伤

### 1. 赭金还是没出现，而且这次把青蓝洗成了灰（色彩）

**证据**

- 金（hue 20–60、sat≥16）**0.43% 帧面积**；按亮度切：`L>120` 占 **65.8%**、`L<40` 只占 **0.6%**、中位 L **158.8**。→ 场上所有"金"都是**星点**，气体里没有金。目标 8–12%，差 20 倍。
- 金进来的代价是可量的：气体带（L 12–60）**平均彩度 21.74 → 13.56（−38%）**、p90 **37.0 → 28.0**、彩度≥16 的占比 **70.0% → 29.4%**。着色面积 39.57% → 17.25%。`c_sky_r4.png` / `c_sky_r5.png` 并排：右图是一条**灰烟**，不是星云。
- 蓝没躲开图例：最终像素色相 **p50 210.0° / p10 202.1°**，「日月」**208.9°**，`±10°` 吃掉 **58.5%** 的着色像素。源色改到 194° 没用——**改的是源，量的是像素**，中间隔着逐通道 exp 压缩和金色混入。

**根因（这次能指到一行）**

```js
dens*=(1-Math.min(0.93,dust));                    // :998  尘埃把密度吃掉
var wG=Math.min(0.45,Math.pow(dust,0.95)*2.6);    // :1002 金又按尘埃分配
var cr=(wB*18 + wM*198 + wG*226)/sum;             // :1005 金是"混色"
```

**金和亮度在结构上互斥**：尘埃重的地方 `dens≈0`（黑），有密度的地方 `dust≈0`（无金）。所以 wG 再怎么抬，金只落在黑里；而每个 wG>0 的像素 b 分量被 "226/78" 这组值往下拽，压缩后就变成灰。**这不是调参能修的，是合成顺序错了。**

**改法：把金从"混色"改成"第二光源"（加性），青蓝/洋红仍走二元混合**

```js
// buildNebulaTex()，:1000–1013
var wM = Math.exp(-Math.pow((dens-0.52)/0.20,2))*Math.min(1,fil*2.4);
var wB = Math.max(0, 1-wM);                       // 金不再参与配比
var sum= wB+wM+1e-4;
var cr=(wB*16 + wM*198)/sum;
var cg=(wB*150 + wM*52)/sum;
var cb=(wB*206 + wM*118)/sum;                     // 蓝再往青 206
var L = Math.pow(dens,1.55)*1.28;
var G = Math.pow(dust,1.55)*0.46;                 // 金自己发光：只跟尘埃走，不乘 dens
d[i4]   = 255*(1-Math.exp(-(cr/255*L*2.2 + G*1.00)));
d[i4+1] = 255*(1-Math.exp(-(cg/255*L*2.2 + G*0.62)));
d[i4+2] = 255*(1-Math.exp(-(cb/255*L*2.2 + G*0.26)));
```

金去点亮**现在最黑的那 20%**（尘带），蓝不再被拉低。若 0.46 仍不够，只调 `G` 的系数，**不要再动 wG 的权重**。

**验收**（同一支 hue 脚本）：金（hue 20–60、sat≥18）**8–12% 帧面积**，其中 `L<60` 的暗金 ≥60%（证明它进的是气体不是星）；气体平均彩度 **≥18**、p90 **≥33**；`日月±10°` **≤45%**；蓝色相 p50 落在 **200–206°**、与 208.9° 拉开 ≥5°。

### 2. 全屏阅读从"黑板"变成"平褐雾"：85% 的像素挤在一个 17 级的带里（光影 / 材质）

**证据**

- 亮度是修好了，但**变成了一张没有纵深的脸**：全页 **84.95%** 的像素落在 L 8–25 这一个带里（R4 是 67.2%；上轮我自己写的目标是"L10–25 占 20–35%"，现在 85%）。std 21.4 几乎全靠文字撑着，**没有文字的地方 std 只有 2.58**。
- **色相中位 42°（棕）**，99.8% 的彩色像素都在暖带。看 `c_full_ink.png`：整页是一层**暖褐色的雾**，右上角的暖光斑（mean 35.15）与左边空旷处（24.56）只差 10.6 个灰阶——读不出光源，读出一层脏。
- **水墨的构图跟文字打架**：`cover + center` 把这幅《登高》图（一个人站在崖上远望）**正对着居中排的诗**——人物的头和肩正好压在 66px 的「登高」和前三行下面（`c_full_src.png` 里看得最清楚）。5.5% 的时候它读作"污渍"，不读作"纸"。

**改法：不要均匀提亮，要"局部提亮 + 冷回去 + 把图移到边上"**

```css
/* ① 冷回去：夜是蓝灰的，不是棕的（现在 :241 的 rgba(28,24,18) 就是那层褐雾的来源） */
#card.reading{background:
  radial-gradient(120% 80% at 50% 0%, rgba(18,22,30,.60) 0%, rgba(5,6,10,0) 62%),
  linear-gradient(180deg,#07080c 0%,#05060a 55%,#04050a 100%)}

/* ② 水墨只留在边缘：中间 42% 是干净的墨地，字压在上面不吃纹理 */
#card.reading .art{
  opacity:.075; filter:grayscale(1) contrast(1.30) brightness(.72);
  background-position:50% 46%;
  -webkit-mask-image:radial-gradient(74% 64% at 50% 46%, rgba(0,0,0,0) 0%, rgba(0,0,0,0) 40%, #000 80%);
```

把 `radial-gradient` 从 `rgba(28,24,18)` 换成 `rgba(18,22,30)` 是这一条的关键——**同一个亮度、不同的温度**：页仍然是"亮"的，但它是墨，不是牛皮纸。

**验收**：页 mean **14–16**；**%L<8 回到 15–20%**（要有真正的黑）；L8–25 占 **45–55%**（现在 85%）；两栏平地 std **2.2–3.5**；着色像素色相中位落在 **200–240°**（冷）而不是 42°；标题后方与页角亮度差 **≥8 个灰阶**，方向应是"边缘有画、中间干净"。

这一轮做对了一件难的事：**把"黑"换成了"有纹理的暗"，而且是水墨给的，不是叠一层灰**（同帧 A/B 的 +4.28 灰阶、std 1.23→2.59 是全片最硬的证据）。但它同时做错了一件更显眼的事：**为了让赭金出现，把金混进了密度场的配色里，结果金没点亮（0.43%，其中三分之二是星点），青蓝先被洗掉了 38% 的彩度，最终色相还正好落到图例「日月」上（差 1.1°）**。阅读页也从"太黑"滑到"太平"——85% 的像素挤在一个 17 级的带里，颜色是 42° 的褐。

**好看的那张封面变难看了，难看的那页内文变好看了。净分 +1：66。**
