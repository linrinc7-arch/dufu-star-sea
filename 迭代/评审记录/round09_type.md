## 三、还剩的三条最伤

### 1. 18 是个常数，于是「页」在 1920 是 47%、在 1366 是 90%

同一首《秋日夔府咏怀》，五个视口给出五种「页」：

| 视口 | 栏数×行数 | 诗块高 | 页高 | 填满 | 下方空白 | 备注 |
|---|---|---|---|---|---|---|
| 1920×1080 | 3 × 6 | 262 | 1,058 | **0.47** | **448** | 右栏 821（1.65×） |
| 1440×900 | 2 × 9 | 393 | 878 | 0.77 | 168 | 每页切一联 |
| 1366×768 | 2 × 9 | 393 | 746 | **0.90** | 46 | 且整页滚 144 |
| 768×1024 | 2 × 9 | 393 | 1,002 | — | — | 栏宽 110 < 行宽 133 |
| 390×844 | 1 × 18 | 513 | 822 | 0.92 | 32 | 唯一「正好一页」的一档 |

- 1920 上每栏只有 6 行 = 262px，而页面能放下 18 行（约 787px）；12 页里有 448px 的空白在每页重复，读者每翻一页都要重新「在空白里找诗」。这是排版问题，不是留白风格问题：**留白应该在页边，不在诗块下面**。
- 打印意义上的页，页脚落在页边距里；现在 `.fs-pager` 紧贴诗块最后一行（margin-top 26px，y=552），属于「跟题」而不是「页脚」。
- 12 页对 200 句本身也偏多：1920 一屏装得下 54 句（3 栏 × 18 行），现在只装 18 句，等于每屏浪费 2/3 的机会，多出 8 次翻页。

**改法：把「每页多少句」交给视口，并且必须是偶数（成联）**

```js
// 2710–2716 —— 页容量跟视口走：列数 × 偶数行（行数必须是偶数，页才断在联上）
var _cf   = document.getElementById('c-full');
var _cols = matchMedia('(min-width:1700px)').matches ? 3
          : matchMedia('(max-width:700px)').matches ? 1 : 2;
var _ln   = parseFloat(getComputedStyle(document.querySelector('#c-full .fs-ln')).lineHeight) || 43.7;
var _rows = Math.max(4, Math.min(18, Math.floor(((_cf.clientHeight || 900) - 210) / _ln / 2) * 2));
var PER   = _cols * _rows;    // 1920: 3×18=54 → 4 页；1366: 2×12=24 → 9 页；390: 1×18=18 → 12 页
```

```css
/* 题名只留在第一页：翻页后降为页眉，别再吃 46–92px */
#c-full .fs-paged .fs-t{font-size:23px;letter-spacing:.2em;line-height:1.4;text-align:left;color:#8f8a7e}
#c-full .fs-paged .fs-a,#c-full .fs-paged .fs-rule{display:none}
/* 落款只留在最后一页 */
#c-full .fs-note[data-last="0"]{display:none}
```

顺带把页脚补成真正的页脚：`第 37–54 句 · 3 / 12`，比裸 `3 / 12` 多一个「我在全诗哪儿」的锚。

### 2. 两栏时每页必有一联跨栏，末页末联被栏线劈开

这不是偶发：18 行 ÷ 2 栏 = 9 行/栏，9 是奇数，**每一页都**有一联跨在栏线上；1440、1366、768 三档全部中招。末页更难看——100 联的最后一联被 `column-rule` 从中间劈开，读者先读到「金篦空刮眼」，眼睛要越过一根竖线才能接「镜象未离铨」。

诗的最小语义单位是「联」，栏和页都只能断在联与联之间。CSS 多栏本身做不到这件事（它按行盒平衡），得把联做成不可分的块。

**改法：联包一层，禁止断开；页数按联均分**

```js
// 2717–2719 —— 一联一个块，栏/页只能在块之间断
for (var i=_from; i<_to; i+=2){
  h += '<div class="fs-cp">' +
       '<div class="fs-ln">'+esc(p.L[i])+'</div>' +
       (p.L[i+1]!==undefined ? '<div class="fs-ln">'+esc(p.L[i+1])+'</div>' : '') +
       '</div>';
}
```

```css
#c-full .fs-cp{break-inside:avoid;page-break-inside:avoid}
```

页边界也别再用「末页剩几句算几句」：200 句 = 100 联，12 页 → 前 4 页 9 联、后 8 页 8 联，末页是 16 句而不是 2 句。

```js
var C = Math.ceil(p.L.length/2);                  // 联数
var pages = Math.ceil(C/PER_C);                   // PER_C = PER/2
var base = Math.floor(C/pages), extra = C%pages;  // 均分，前 extra 页多 1 联
var nC = base + (_pg < extra ? 1 : 0);
```

### 3. 翻页控件只认鼠标：35×30、不可聚焦、方向键在转天幕

- `.pgb` 是 `<span>`，`tabIndex=-1`、无 `role / aria-label`，指针被自定义光标接管（`cursor:none`）；键盘用户 Tab 不到它。
- 实按 →/←/PageDown/Space：**页码不动**，`cam.yaw` 动了——在整屏读里按方向键，等于在卡片背后徒手转星海，读者看不见任何反馈。
- 首末页没有禁用态：`1 / 12` 的「‹」与 `12 / 12` 的「›」都是 `opacity 1`、同色边框，点了没反应也不告诉你为什么。
- 命中 35×30，手机上也一样；计数 `1 / 12` 宽 45px、`10 / 12` 宽 53px，箭头随之左右跳 4px——连点「下一页」时按钮会在指下微移。
- 12 页的长诗，读者最想知道的是「这是全诗的哪一段」，页脚只有 `3 / 12`。

**改法：换成 button、给禁用态、接管方向键、数字定宽**

```js
// 2721–2723
h += '<div class="fs-pager" role="group" aria-label="翻页">' +
     '<button class="pgb" data-d="-1" aria-label="上一页"'+( _pg<=0 ? ' disabled':'')+'>‹</button>' +
     '<span class="pgc">第 '+(_from+1)+'–'+_to+' 句 · '+(_pg+1)+' / '+_total+'</span>' +
     '<button class="pgb" data-d="1" aria-label="下一页"'+( _pg>=_total-1 ? ' disabled':'')+'>›</button></div>';
```

```css
#c-full .pgb{min-width:44px;min-height:44px;display:inline-flex;align-items:center;justify-content:center;
  background:none;font:inherit;color:inherit}
#c-full .pgb[disabled]{opacity:.26;pointer-events:none}
#c-full .pgc{font-variant-numeric:tabular-nums;min-width:9.5em;text-align:center}
```

```js
// 2291 的 window.keydown 里，进门第一件事：阅读态先翻页，再谈相机
if (readingOn && !typing && /^(ArrowLeft|ArrowRight|PageUp|PageDown| )$/.test(e.key)){
  e.preventDefault();
  fsPage((e.key==='ArrowLeft'||e.key==='PageUp') ? -1 : 1);
  return;
}
```

## 四、还有这些（不单列分，但下轮该顺手做掉）

1. **「生涯」是 16px，越阶。** `#sy2 .lab`（598 行）没有规则，字号从 `#foot` 继承成 16px，而同排 `#dims / #mode / #view / #sy / #au` 的 `.lab` 全是 12.5px。上轮已提，这轮仍在。补一行即可：`#sy2 .lab{font-size:12.5px;letter-spacing:.3em;color:#8a8578;margin-right:12px;font-family:"Helvetica Neue",Arial,sans-serif}`。
2. **11 字行会穿栏线。**《往在》（65 句，最长 11 字）1920：一行 **267px**，栏宽 198，左右各溢 34.8px，穿过 26px 的半栏距、压到栏线上 8.7px；1366 是 267 vs 218。四首长诗（往在 / 夔府书怀 / 送重表侄 / 八哀诗 王思礼）里有 9–11 字行，建议 `#c-full .fs-left.long .fs-ln{font-size:clamp(19px,1.55vw,23px)}`，或对 `maxLen>=9` 的诗降一档字。
3. **行尾字距让居中行整体左偏。** `letter-spacing:.16em`（23px 下 3.68px）会加在最后一个字后面，居中时整行视觉重心左移 1.84px。`.fs-ln::after{content:'';margin-right:-.16em}` 一行可正。
4. **卡内联距 16px 还没收。** 现在的 41.8px pitch 读起来像「每联一段」，不算错；但 451px 的卡宽里每行只占 300px，右侧 150px 全空。要么把联做成两端对齐（出句贴左、对句贴右），要么居中，别让它看起来像左对齐的清单。
5. **1366 右栏被折线切 144px。** `.fs-right` 内容高 821px，`#c-full` 可视 746px，末节「说明」在折线下——整屏读里出现纵向滚动，和「分页消除滚动」的初衷相抵。给右栏 `max-height:calc(100vh - 120px);overflow:auto`，或把「机器同题」段折叠。

## 五、一句话给下一轮

分页这个机制是对的，问题全在「页」的度量上：**把每页句数交给视口、把联做成不可断的块、把翻页从 `<span>` 换成 `<button>` 并接住方向键**——这三件做完，1920 的 47% 会回到 90%，12 页会变成 4–6 页，跨栏断联和末页两半会一起消失。那时候这一屏才配得上「整屏读」三个字。
