### 空气层：从 520 挪到 1400，耳朵上没发生

| 对象 | 峰值 | 100 ms RMS | 质心 | 1200–1700 Hz 占比 |
|---|---:|---:|---:|---:|
| 旧空气（520/Q0.4/g0.02） | −47.4 | **−58.0** | 2087 Hz | 11.1% |
| 新空气（1400/Q0.75/g0.03） | −41.6 | **−53.2** | **2912 Hz** | 20.6% |
| 底噪（drone+air） | −21.9 | −29.3 | 93 Hz | 0.1% |

三件事叠在一起：

1. **它还是听不见。** 新空气比底噪低 23.9 dB；更糟的是真机上 `audFollow` 第一帧就把它从 0.030 拉到 **0.0158**（`0.008 + vis/900*0.030`，vis≈235），又削 5.6 dB，实际约 **−58.8 dBFS**，比底噪低 29.5 dB。
2. **它也不在 1400 Hz。** 带通 Q0.75 的 6 dB/oct 尾巴把大半能量放到 2 kHz 以上：这一层 66.9% 在 1–4 kHz、20.6% 在 4 kHz 以上，只有 20.6% 落在 1200–1700。听感是「磁带嘶声」，不是「空气」。
3. **它和一声 hover 一样响。** 整层空气峰值 −41.6，hover 峰值 −40.1：**整片夜色的峰值，只比一次悬停提示高 1.5 dB**。这已经不是「轻」，是「不存在」。

顺带把「呼吸」也量了：24 个朝向的可见伪诗数 223–254（只差 12%），代入公式 air 增益 0.0154–0.0165，**0.6 dB**；`audFollow` 注释写「让空气层的高频跟着走」，但代码里改的是 `AUD.lp`——那条链只到 drone，空气链 `src→bp→ag→master` 根本不经过 lp。频点从头到尾钉在 1400。

## 三、三条最伤（按「声音能不能成为作品的一部分」排）

### 1. 记忆恢复＝「开着的静音」：声音层对用户说了假话

这是现在唯一还带「欺骗性」的问题：**它不挡读诗，但它让「开」这个字失去信用**。上一轮是 P0 遮住了它；P0 修好之后，它就成了声音层最靠前的一道门。

实测（`behavior8b.json`）：`on=true / ctx=suspended / t=0 / master=0`，标签「开」，`ctxLog` 里 create 与 resume 都停在 suspended。点天幕不醒；点开关先变「关」，第二次才响。

**改法（约 20 分钟）**：把「意愿」和「状态」分开，只在 `ctx.state==='running'` 之后写「开」。

```js
// web/index.html:1754 的恢复段：只记意愿，不写标签
if(localStorage.getItem('dsh_sound')==='1'){
  AUD._pendingOn = true;
  var a=document.getElementById('autog'); if(a) a.textContent='点此开启';
}
// 首次手势里真的 resume，成功了才翻「开」
document.addEventListener('pointerdown', function once(){
  document.removeEventListener('pointerdown', once);
  if(!AUD._pendingOn) return;
  var c=audInit();
  c.resume().then(function(){
    if(c.state==='running'){ audToggle(true); }
    else { var a=document.getElementById('autog'); if(a) a.textContent='关'; }
  });
}, {once:true});
// audToggle 末尾：ctx 没 running 就不许写「开」
```

**验收**：预置 `dsh_sound=1` 重载 → 标签**不是**「开」（显示「点此开启」/「关」）；点一下天幕 → `ctx.state==='running'`，2.5 s 内听到钟；全程没有「开而无声」的状态。

### 2. 界面音仍不是一套系统；而这轮把三个「发现」做成了无声

上一份声音评审里的五类界面音没动，电平也没归一：

| 类 | 峰值 | 100 ms RMS | 质心 | 听感 |
|---|---:|---:|---:|---|
| hover | **−40.1** | −55.3 | 1568 Hz | 比底噪 RMS 低 26 dB，等于没有 |
| type | **−44.9** | −60.9 | 1545 Hz | 全系统最轻，几乎不可闻 |
| filter | −30.5 | −40.0 | 196 Hz | 95.8% 在 200 Hz 以下，小喇叭上只剩触感 |
| panel | −30.6 | −40.0 | 110 Hz | 200 Hz 以上零能量（−101 dB） |
| zoom | **−17.4** | −30.8 | 2225 Hz | 比十档磬（−17.9…−18.7）还高 0.5–1.3 dB |

内部极差 **27.5 dB**。更关键的是**覆盖**：这轮新增的交互，一个都没接 cue：

| 动作 | 触发方式 | 实测 cues |
|---|---|---|
| 悬停换星 | `pointermove` | `hover` ×2 ✓ |
| 图例项 | `#legend .lg` | `filter` ×1 ✓ |
| **图例开合** | `#lgtog` | **∅** |
| **左导航悬停（展开标题）** | `#side .sb` | **∅** |
| **左导航切章** | `#side .sb` | **∅** |
| 声音开关 | `#autog/#csound` | ∅（只有电平斜坡） |
| 全屏/退出 | `#readtoggle` | ∅（只有 duck） |
| +/− | 键盘 | `zoom` ✓ |
| 检索输入 | `input` | `type` ✓ |
| 着色/检索维度/诗云 | click | `filter` ✓ |
| 面板 | `#panel` | `panel` ✓ |

声音层的「语义重量」和它的「电平/覆盖」是反的：**最不承载意义的 zoom 最响；这轮最需要被听见的三个「发现」（导航展开、切章、图例铺开）一声不响；而最轻的 hover 恰好是唯一有声音的悬停。**

**改法（约 1.5 小时）**：

(a) 给界面音一条独立总线，写一次电平：

```js
// audInit 里 conv/wet 建好之后
AUD.cue = ctx.createGain(); AUD.cue.gain.value = 0.30;
AUD.cue.connect(AUD.master);
var cw = ctx.createGain(); cw.gain.value = 0.12;
AUD.cue.connect(AUD.conv);          // conv→wet→master 已在链上
```

(b) 五类统一到「峰值 −30±3」，并且每一类给 2–4 ms 噪声瞬态（纯正弦在 1.5 kHz 上听不出「一下」）：hover 2093 Hz + 4 kHz 噪声 6 ms；type 2.2 kHz 噪声 8 ms；filter 262 Hz + 2.6 kHz 10 ms；panel 196 Hz + 1.5 kHz 12 ms；zoom 600 Hz 带通 140 ms、增益收到 −30。

(c) 把新交互接上（三行）：

```js
document.getElementById('lgtog').addEventListener('click', function(){ audCue('panel'); }, true);
[].forEach.call(document.querySelectorAll('#side .sb'), function(b){
  b.addEventListener('pointerenter', function(){ audCue('hover'); });

```

### 3. 空气层是空操作，夜没有中频；钟还在底噪下面

这一条是「声音层作为环境」的全部：**现在真正听得见的只有磬、纸、事件音；「夜」是一层 55/82.5 Hz 的嗡鸣，在笔记本上 95% 的能量落在小喇叭听不见的那一半。**

- 底噪：−29.3 RMS / 质心 93 Hz / **94.6% < 200 Hz**。
- 空气：−58.8 RMS（真机）/ 质心 2912 Hz / 只占底噪能量 0.1%。
- 钟：6 次中位 **−24.7 峰值 / −31.4 RMS**，比底噪（−29.3）**低 2.1 dB**，也低过底噪峰值 2.8 dB。
- 「呼吸」：0.6 dB。

**改法（约 1.5 小时）**：

```js
// audInit：空气改成「可闻的一层」，并用低通把 6 dB/oct 的尾巴收住
var bp=ctx.createBiquadFilter(); bp.type='bandpass'; bp.frequency.value=900; bp.Q.value=0.7;
var lp2=ctx.createBiquadFilter(); lp2.type='lowpass'; lp2.frequency.value=2400; lp2.Q.value=0.5;
var ag=ctx.createGain(); ag.gain.value=0.12;          // 先把 air-only 抬到 ≈ −42，再谈呼吸
src.connect(bp); bp.connect(lp2); lp2.connect(ag); ag.connect(master);
AUD.airBP=bp;

// audFollow：呼吸驱动「空气带通」而不是只改 gain；用 zoom 当信号（vis 几乎是常数）
var p = Math.max(0, Math.min(1, (cam.zoom-0.8)/1.6));
AUD.airBP.frequency.setTargetAtTime(650 + 650*p, t, 0.9);   // 650→1300
AUD.air.gain.setTargetAtTime(0.09 + 0.07*p, t, 1.2);        // 0.09→0.16
```

钟也补回来：分音 `0.09/0.035/0.014 → 0.14/0.055/0.022`（+3.8 dB，目标 RMS ≥ 底噪 +2 dB）；再在 `select()` 后 1.5 s 内跳过随机钟（本次实测里点星当秒就撞上一次钟，两个都在 200–800 Hz，会打架）。
**顺带**：钟的五个音 `[392, 523.25, 587.33, 698.46, 783.99]` 是 G–C–D–F–G，而磬是 **G 五声（G A B D E）**：C 是偏音、F 是♭7，F5 撞磬的 E5 是小二度。把钟改成同一宫 `[392, 440, 493.88, 587.33, 659.25]`，不谐分音 `2.01/3.02` 保留（那是青铜）。

**验收**：air-only RMS ≥ −44 dBFS；笔记本 50% 音量、安静房间能听出「有一层空气」；转 180° 空气带通中心变化 >300 Hz（现在 0 Hz）；钟 RMS ≥ 底噪 +2 dB。

## 一句总评

上一轮我说「先让它别坏，再让它成一套，最后才轮到让它在笔记本上听得见」。这一轮把「别坏」做到了——开声点星，卡开了，声音第一次没有掐住产品。但「成一套」和「听得见」都还停在原地：界面音跨 27.5 dB，新做的三个「发现」全是静音；空气层挪了 880 Hz，却只响了 4.8 dB，仍然埋在一层听不见的 55 Hz 嗡鸣下面。**声音层现在不会伤人了，但它还没有开始说话。**
