## 这 +9 是挣来的（逐条对账）

1. **干路重复删掉了。** 旧 `audSelect` 在 `out.connect(AUD.master)` 之后又接 `AUD.dry`（0.65），同一信号相加；15:05 起只走 `dry` + `conv`（1841–1847）。离线复刻：选诗音峰值 **−9.8 → −17.8 dB**，100ms RMS **−18.3 → −25.8**；底噪 **−25.3 → −29.5**，钟 **−27.3**，选诗 **−25.8**，伪诗 **−25.3**。层级从「UI 音最响」翻成「底噪 < 钟 < 选诗 ≈ 伪诗」——这是本轮最实的一分。
2. **伪诗有了自己的嗓子。** 新 `audNoiseVoice`（1803）用 146.83Hz triangle、两个分音、1.4s、**不进混响**；真诗仍是 196Hz 青铜、四非谐分音、3.4s、wet 0.42。离线：伪诗质心 **161Hz**、选诗 **370Hz**；伪诗不再和《登高》同一记音。机器「没有房间」这句设计话，第一次落到了声音上。
3. **声像跟屏幕了。** 真诗改为 `p._q ? (p._q.sx/W - .5)*1.6 : 0`（2065 行）。实测：默认视角点屏幕 x=629 的星，pan **−0.2758**；转 90° 后点 x=1293 的星，pan **+0.2777**——都与 `(sx/W−.5)*1.6` 一致。上一轮「转 90° 有 44% 与屏幕相反」的问题，真修好了。
4. **底噪往中频挪了一点。** gain 0.05→0.032、lowpass 220→420、三角波 110→220。离线：质心 **72 → 79Hz**、<200Hz **100% → 95%**、200–1k **0% → 5%**。方向对，幅度远远不够（见问题 2）。
5. **页脚 aria 与命中区。** `#autog` 开声后 `aria-checked="true"`（实测）；1366 下 36×26 → **44×32**，1920 下 **52×36**；`#csound` 文案在 `audToggle` 里即时更新（不再等 600ms）。
6. **15:03 / 15:14 的上下文修复**：滚动条改成金 5px（`#card #c-poem`，计算值 `rgba(201,162,39,.55)`）；Esc 变成两段式（先退阅读，卡保留；实测 `cardOn=true`）；手机底栏 **266px → 192px（31.5% → 22.7%）**，侧栏隐藏、筛选行不换行。

此外，14:46 那版真正挣到的 +1 仍在：白噪音卡的 `ReferenceError` 修好后，伪诗那一记音第一次能响；手机全屏单列后，390 宽能读完《登高》（1.47 屏、无叠字）。

## 这一轮仍然没有挣到的

- **记忆恢复是「静音的开」。** 预置 `localStorage.dsh_sound='1'` 后刷新，4.2s 时 `AUD.on=true`、标签「开」、`aria-checked="true"`，但 `ctx.state='suspended'`、`t=0`、`master=0`——完全没声。第一次点天幕才 running，master 从 0 爬；用户看到「开」却没声，去点开关那一下把它关掉，得点第二次才出声。
- **`#csound` 仍无 `aria-checked`**（实测 `null`）；全屏「声音 开／关」与「退出」同为实心金（`sameGold=true`）；`#csound` 68×24，`#autog` 高度 32–36，仍不到 44。
- **阅读中开声不 duck**：先开声再进阅读目标 0.42；在阅读里关掉再开目标 0.85（1s 实测 0.42 / 0.772）。`audDuck` 在 `AUD.on=false` 时直接 return（1857），不会在状态变化时补。

- **钟仍然干、仍然随机。** 100ms RMS −27.3、峰值 −20.6，比新底噪高 2.2dB，但直接接 master、**不进卷积**；9–22s 的间隔听起来仍像通知音。
- **白噪音墙仍无声**：`setSy()` 只切渲染与文案；整面机器诗开合一声不响。
- **真诗仍只有一记 196Hz**：`audSelect` 不接受 base/dur/wet，所有真诗同一音高、同一时长；伪诗声像仍按 `po.dir.x*0.8`（世界 x），只有真诗改成了屏幕。

## 三条最伤（按「声音能不能成为作品的一部分」排）

### 1. 开关仍然不可信：记忆恢复是静音的开，csound 没有 aria，命中高度 32–36，全屏两块金

**证据**

- **记忆恢复**：预置 `dsh_sound=1` 刷新，4.2s 时 `on=true / aria=true / label=开 / ctx=suspended / master=0`；第一次点天幕才 running（master 0.8s 后 0.659）；点开关先关（`on=false, master=0`），第二次才真开。**这不是「记住」，是「记住了一个假的开」。**
- **aria**：`#autog` 已修（false→true）；`#csound` 仍是 `aria-checked=null`，读屏会报「声音，开关」而没有状态。
- **命中**：1920 52×36、1366 **44×32**、390 50×36；`#csound` 68×24。宽度到了 44，高度没到。
- **全屏双金**：`#card.reading .readtoggle`（289 行）只看 `.reading`，不看 `AUD.on`；「声音 关」与「退出」同为 `rgb(201,162,39)` 实心金（图 4/5）。
- **duck 随顺序**：先开声进阅读 0.42；在阅读里开声 0.85（1s 实测 0.42 / 0.772）；`audDuck` 在 `AUD.on=false` 时直接 return，不补状态。

**为什么伤**：声音是可选层，**开关就是产品**。一个「看起来开了、其实没声」的开关比没有开关更伤信任；一个读屏没有状态的开关等于没做；一个 32px 高的目标在 1366 笔记本上要瞄准；全屏两块金让用户无法从颜色判断。声音层现在有内容了，但入口仍然在骗人。

**改法（约 1 小时）**


### 2. 「夜」还是不在笔记本上：底噪 95% <200Hz，呼吸只动 8Hz，钟仍然干

**证据**（离线复刻，master=1.0，单声道口）

| 对象 | 100ms RMS | 峰值 | 质心 | <200Hz | 备注 |
|---|---:|---:|---:|---:|---|
| 底噪（15:18） | −29.5 | −22.2 | **79 Hz** | **95%** | .032 / lowpass 420 / 55+82.5+220 |
| 选诗音（修好后） | −25.8 | −17.8 | 370 Hz | 50% | dry .65 + wet .42，无直连 |
| 伪诗声 | −25.3 | −17.1 | 161 Hz | 93% | 146.83 triangle、1.4s、无混响 |
| 随机钟 | −27.3 | −20.6 | 688 Hz | 0% | 只接 master，**无卷积** |
| 旧选诗音（对照） | −18.3 | −9.8 | 267 Hz | 79% | 直连 + dry + wet |

- **底噪仍在滚降区。** 55/82.5Hz 两根正弦 + 220Hz triangle 过 420Hz lowpass；95% 能量 <200Hz，质心 79Hz。笔记本小扬声器 200Hz 以下掉 10–20dB，这一层仍然基本听不见；耳朵先听到的是 −25.8 的选诗音。
- **呼吸还是假的。** lp 380→800 + air 0.008→0.038：质心 **77 → 85Hz（+8Hz）**、RMS **−0.1 dB**。上一轮 +0Hz，这一轮 +8Hz，仍然是「参数在动、耳朵没动」。
- **钟与房间。** 钟 100ms RMS −27.3，比底噪高 2.2dB，层级终于对了；但它直接接 master，**不经过 1.8s 卷积**。夜色里唯一持续出现的那一记，反而没有房间；选诗那一记有。9–22s 的随机间隔也仍像通知音。
- **duck 仍压总总线**：0.85→0.42（−6.1 dB），选诗/钟一起变轻；阅读时没有独立的「bed」可压。

**为什么伤**：这一轮把「层级」修对了（底噪 < 钟 < 选诗），但**音色仍落在笔记本听不见的那一半**。作品想给「夜 / 星海 / 青铜」，在交付设备上仍是「很轻的一声叮 + 一层几乎听不见的嗡」；视觉这一轮反而亮了 2.36×，两边更不在同一个空间。

**改法（约 1.5 小时）**

**(a) 底噪再加一层中频**（保留现在的 55/82.5/220，另加 220/277/330 的 mid，lowpass 900，air 抬到 0.06–0.08）

```js
var mid=ctx.createGain(), lpMid=ctx.createBiquadFilter();
lpMid.type='lowpass'; lpMid.frequency.value=900; lpMid.Q.value=.5; lpMid.connect(mid); mid.connect(master);
[[220,.020],[277.18,.014],[329.63,.010]].forEach(function(p){ var o=ctx.createOscillator(); o.type='sine';
  o.frequency.value=p[0]; var g=ctx.createGain(); g.gain.value=p[1]; o.connect(g); g.connect(lpMid); o.start(); });
```

目标不是「更响」，是让 200–1k 的能量从 5% 到 20–25%；离线试算这组约 24% <200、72% 在 200–1k，质心 330Hz。

**(b) audFollow 接到 air 的带通与增益上，删掉 AUD.lp 那两行**

```js
AUD.airBP.frequency.setTargetAtTime(500+600*pitch01, t, .5);   // 500→1100Hz
AUD.air.gain.setTargetAtTime(0.04+0.08*vis, t, .8);            // 0.04→0.12
```

试算：质心 212→449Hz（+237Hz），RMS +0.4 dB——这才是「呼吸」。

**(c) 钟要有房间**：接 `AUD.conv`（wet .25），按峰值 −18～−19 定电平；间隔放到 20–40s。
**(d) 分总线**：`AUD.bed` / `AUD.cue`，duck 只压 bed −8dB，cue 不动；阅读时再加一点 wet 或一层纸声，让「水墨的房间」有对应的声学。

**验收**：笔记本（或 200Hz 高通模拟）上底噪可闻；选诗音 ≤ 底噪 +3dB；钟 ≥ 底噪 +2dB；阅读 duck 只压 bed；转头 30° 质心变化 >100Hz。

### 3. 语法只做了一半：伪诗有声了，白噪音墙还是哑的；真诗仍只有一记 196Hz

**证据**

- **修好的一半**：`audNoiseVoice` 让伪诗有了 146.83/1.4s/无房间的嗓子；真诗 196/3.4s/wet；屏幕声像也已修（图 3 的实测）。这两件是本轮最漂亮的声音改动。
- **没修的一半：墙。** `setSy()`（1697–1703）只切 `noiseOn`、改文案、重绘；整面白噪音墙开合时一声不响。作品叫「诗云」，声音层却绕开了「云」。
- **真诗仍只有一记音。** `audSelect` 的 `base=196` 写死，所有真诗同一音高、同一 3.4s；只有伪诗/真诗两类，没有按意象类别分。1468 首真诗在耳朵里仍是一个音。
- **覆盖仍薄。** 选诗覆盖星、检索回车、面板跳转；悬停、检索输入、着色、图例、时期、面板 00–04、关键词胶囊、缩放、诗云开合仍全静音。十余类交互里，声音只对「进入一首诗」有语义。
- **伪诗声像仍按世界 x**：`audNoiseVoice(po.dir.x*0.8)`；真诗已按屏幕，伪诗没有。

**为什么伤**：核心对照是「机器能穷尽组合，判断不出哪首是好诗」。现在耳朵能分出真/伪了，这是大进步；但「诗云」这个名字所指的那面墙、以及除了选诗之外的绝大多数交互，仍然没有声音。声音层刚学会两句话，还没有成为这套星海的第二种语言。

**改法（约 3 小时）**

**(a) 诗云开合给一次空气涌起**：`setSy()` 里把空气层从 0.02 提到 0.06（1.5s），关掉时回落；这是整面机器诗唯一能被听见的地方。
**(b) 真诗按意象类别取五声音阶**：

```js
var PENTA=[196,220,246.94,293.66,329.63];
function poemBase(p){
  var i=(D.cats||[]).findIndex(function(c){return c.id===p.d;});
  if(i<0){ i=0; for(var k=0;k<p.t.length;k++) i=(i*31+p.t.charCodeAt(k))%5; }
  return PENTA[i%5];
}
audSelect(pan, poemBase(p));   // audSelect 增加 base 参数
```

**(c) 三个便宜的节点音**：悬停真诗 320ms 的 −36dB 1.8k tick；检索回车加 `audPaper()`；时期/图例高亮一记 1.2s 的 110→82Hz 低频涌起。
**(d) 伪诗声像也改屏幕**：`audNoiseVoice` 接收 `po._q.sx`，不要再用 `po.dir.x`。

**验收**：盲听 10 组真/伪 ≥8/10；悬停、检索回车、时期、诗云开合四处有声且不高于选诗音 6dB；诗云开合 200ms 内有可闻变化。
