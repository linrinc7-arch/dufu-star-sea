### 1.2 空气层：写的是 0.12，跑的是 0.0158

这是本轮最需要被指出的一件事，因为它花的力气最大、到耳朵的路程最短：

```
0.076 (t=2.3s) → 0.027 (4.3) → 0.0179 (6.3) → 0.0162 (8.3) → 0.0158 (10.3, 之后不变)
```

`audFollow` 的目标值是 `0.008 + min(0.030, vis/900*0.030)`；实测 24 个朝向的可见伪诗数是 **223–254**（只差 12%），代入得 **0.0154–0.0165**——和第 8 轮**完全同一个数**。所以：

- 标称 **+12 dB**（0.030 → 0.12）在稳态只剩 **+2.6 dB**（0.0158 下 2400/Q0.6 比 1400/Q0.75 亮 2.6 dB）。
- 稳态下这一层比底噪 RMS 低 **25 dB**，峰值还比一声 hover 低 **13.5 dB**。
- 更糟的是它的频谱位置：**44.4% 的能量在 4 kHz 以上**，只有 33.7% 落在 1.7–3.4 kHz。2400/Q0.6 的 6 dB/oct 尾巴把"空气"做成了"磁带嘶声"——第 8 轮我写的是同一句话，一轮之后还在。

## 二、三条最伤（按"声音能不能成为作品的一部分"排）

### 1. 空气层仍然是空的，而且这次是"参数写对了、被自己覆盖"

这是现在声音层唯一的"假动作"：`audInit` 里把 `ag.gain.value` 设成 0.12，4 秒后 `audFollow` 把它拉回 0.0158，而且**永远不会回来**。用户听到的"夜"，1 kHz 以上只有 0.3% 的能量。

**证据链**：代码 `1880`（0.12）× `2059–2060`（覆盖）× 真机 8 次采样 × 隔离实测（0.12 → −38.6 RMS；0.0158 → −56.2 RMS）× `visRange`（223–254 → 目标 0.0154–0.0165）。

**改法（约 30 分钟）**：让 `audFollow` 在**基线**上调制，而不是重写：

```js
// audInit：把"基线"和"呼吸"分开，基线要一次到位
var ag=ctx.createGain(); ag.gain.value=0.06;      // ← 0.06 ≈ 空气单独 −44.6 dBFS
AUD.airBase=0.06;
// 顺手收掉 4 kHz 以上的嘶声：带通后面再串一只低通
var lp2=ctx.createBiquadFilter(); lp2.type='lowpass'; lp2.frequency.value=3200; lp2.Q.value=0.5;
src.connect(bp); bp.connect(lp2); lp2.connect(ag); ag.connect(master);
AUD.airBP=bp;

// audFollow：围绕基线呼吸，并且让"带通"跟着画面走（不是只改 gain）
var p=Math.max(0,Math.min(1,(cam.zoom-0.8)/1.6));            // 用 zoom 当信号，vis 几乎是常数
AUD.air.gain.setTargetAtTime(0.045+0.030*p, t, 1.2);          // −47.9 … −41.4 dBFS
AUD.airBP.frequency.setTargetAtTime(1700+900*p, t, 1.1);
```

**验收**：air-only RMS **≥ −46 dBFS**；笔记本 50% 音量、安静房间能听出"有空气"；`zoom` 从 0.8 拉到 2.4，空气带通中心变化 **>300 Hz**（现在是 0）；稳态 1 kHz 以上占比 **≥ 8%**。

### 2. 中频层是两条不动的纯音，而且绕开了那条"跟画面走"的滤波器

`g3.connect(master)`（`1871`）——中频层**跳过 `lp`**。于是：

- `audFollow` 把 `lp` 从 620 扫到 268（俯仰 0）→ 447（+1.25）→ 484（−1.25），**但它调的是只剩 55/82.5/330 Hz 的那条链**；441/657 是唯一在小喇叭上听得见的，恰恰不受它影响。所以"转头时声音跟着画面动"这件事，从这轮起在耳朵上**归零**。
- 而且它是静止的：中频层包络变异系数 **0.023**（2.3%），441 / 657 两条线占掉它 **79%** 的能量。一条永远不变的 A4+E5 五度，在 −40 dBFS 下连续播放，读起来是**设备嗡鸣**，不是"夜"。它和钟的关系也不总是干净的：钟的 B4（493.88）与底噪 A4（441）是**大二度**，钟的 D5（587.33）与底噪 E5（660.5）也是**大二度**——五音里有两音会撞。底噪 660.5 和钟的 E5（659.25）还差 **3.3 音分 → 1.25 Hz 的拍**。

**改法（约 1 小时）**：两个动作，一个修架构、一个给生命。

```js
// audInit：中频给一条自己的低通（audFollow 同步扫它），再加一个 0.05 Hz 的极慢呼吸
var g3=ctx.createGain(); g3.gain.value=0.010;
o4.connect(g3); o5.connect(g3);
// 注意：不要接到 lp——lp 后面还串着底音那级 0.024，接上去等于再乘 0.024（−32 dB，中频就没了）
var midLP=ctx.createBiquadFilter(); midLP.type='lowpass'; midLP.frequency.value=620;
g3.connect(midLP); midLP.connect(master);
AUD.midLP=midLP;
var lfo=ctx.createOscillator(), lg=ctx.createGain();
lfo.frequency.value=0.05; lg.gain.value=5;       // ±5 音分，20 s 一个来回
lfo.connect(lg); lg.connect(o4.detune); lg.connect(o5.detune); lfo.start();
AUD.mid4=o4; AUD.mid5=o5;

// audSelect / select() 末尾：让"夜"跟着你选的诗走——底噪的两个音跟到这首诗的磬位
if(AUD.mid4 && AUD.mid5){
  var f=196*Math.pow(2,_pent[_deg%_pent.length]/12);
  AUD.mid4.frequency.setTargetAtTime(f*2, t, 1.2);   // 高八度，392–1318 Hz
  AUD.mid5.frequency.setTargetAtTime(f*3, t, 1.2);   // 十二度，588–1977 Hz
}
```

第二段是这次最值得做的一件小事：**你点开《登高》的那一下，整个夜会跟着沉到那个音上**——静止的嗡鸣立刻变成"这个空间在回应你"，而且完全同宫。做完这一条，第 2 条和第 3 条（耦合）会一起长。

**验收**：盲听 3 首不同诗，能分出底噪落点不同（频率差 ≥ 100 Hz）；连续听 3 分钟不觉得"机器在响"；`midLP` 从 268 扫到 484 时，中频层可测电平变化 ≥ 1.5 dB（现在 0 dB）。

### 3. 事件层还是倒着的：纸比磬响，伪诗比真诗响，最响的界面音是最不该响的那个

这一层的相对关系是"作品在说什么"的直接体现，现在是反的：

| 事件 | 峰值 | 100ms RMS | 质心 | 应处的位置 |
|---|---:|---:|---:|---|
| **开卡那一下**（磬+纸） | **−13.7** | −24.9 | 315 Hz | 全场最响，可以 |
| 磬 select（十度） | −17.2…−18.3 | −24.6…−25.9 | 194–657 | 主角 |
| **纸 paper** | **−17.6** | −33.3 | **3785 Hz** | 只该是"翻页的余韵" |
| **伪诗 voice** | **−17.1** | **−24.2** | 161 Hz | 必须**低于**真诗 |
| 钟 bell（五音） | −19.0…−20.1 | −25.6…−28.0 | 393–657 | 背景 |
| 界面音 zoom | −24.5 | −38.9 | 2197 Hz | 只该是"提示" |

- 纸单独 **−17.6**，和磬最响的一度（−17.2）只差 **0.4 dB**、比最轻的一度（−18.3）还响 0.7 dB，而它的质心在 **3.8 kHz**——开卡那一下最抢耳朵的是一声高频嘶声，不是磬。第 8 轮写的"开卡那一下最响的是纸"，一轮之后从 −17.7 挪到 −17.6，**没动**。
- 伪诗 **−17.1 / −24.2**，比真诗（磬 RMS −24.6…−25.9）**响 0.4–1.7 dB**，比钟也响。作品花了很大力气说"机器写的不如杜甫"，声音却在说"机器的更重"。
- 界面音里最响的仍是 zoom（−24.5），它比磬低 7.3 dB、比 hover 高 7.8 dB——按键缩放是这层声音里"最不重要却最响"的动作。

**改法（约 40 分钟，都是数字）**：

```js
// audPaper：0.22 → 0.09，带通 2200/Q0.9 → 2600/Q1.2（收窄，别铺满 4 kHz），并延后 30 ms
var g=ctx.createGain(); g.gain.value=0.09;
// audNoiseVoice：0.20/0.05 → 0.11/0.028（−5.2 dB），让伪诗落在真诗下面 3 dB
var parts=[[1,0.11],[2.0,0.028]];
// audCue：五类压到 −34…−30
hover  og 0.018 → 0.018，ramp 1.35 → 0.85      // −32.3 → −36.3
type   0.012 → 0.020                            // −38.9 → −34.5
zoom   ramp 0.20 → 0.10                         // −24.5 → −30.5
filter/panel 不动                                // −30.5 / −30.6
// audSelect 末尾：把随机钟往后推，别和磬撞在同一秒
clearTimeout(AUD.timer); AUD.timer=setTimeout(audBell, 4000);
```

**验收**：`peak(paper) ≤ peak(select) − 6`；`peak(voice) ≤ peak(select) − 3`；五类界面音极差 **≤ 6 dB**，且 `peak(zoom) ≤ peak(select) − 8`；开卡 1.5 s 内不再叠第二记钟。

## 六、评审之后：19:24 的源码已经先走了一步（但单文件没跟上）

我写完上面这些数字之后，`web/index.html` 在 **19:24:56** 被改过一次（声音段 9,997 字符，sha `fb1cba9c`），逐行对着我这份报告改的：

1. **单文件没吃到这次修改。** `杜诗星海.html` 在 19:25:40 重打过一次（3,315,555 B），但里面的声音段仍是 9,675 字符 sha `ec4e6f86`——**19:00 的那一版**。本报告 72 分对应的、用户双击能听到的，就是这一版。按上表，若把 19:24 的源码重新打包并修掉中频这条，我预计落在 **76–78**（空气与事件层到位，中频的"活"还没做完）。
