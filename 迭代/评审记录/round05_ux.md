## 仍然最伤的三条

按「找到 → 点开 → 读完」排，不按字数。

### 1. 找到：首屏仍然没有一个诗题；1366 和手机甚至没有一句操作提示

- 全站 `fillText` = **0**；1920 首屏上可见文字 58 条，全是导航、图例、说明、计数，**没有一个诗题**。触屏没有 hover，「点星读诗」在手机上就是盲点。
- 检索框 187×24，`input` 只有 **150×16**；placeholder `#3F3D37` 实测 **1.83:1**；聚焦后 `#2F2D28` 反而更暗。`POEMS 1468 · 712—770` 是 9px、`#55524A`、**2.55:1**。全站唯一的入口控件，是这一屏最看不清的东西。
- `@media (max-width:1500px){#hint{display:none}}`：**1366 笔记本和 390 手机都没有「拖动 巡游 / 点击星辰 读诗」提示**。1920 才有。也就是说，最常用的两种屏，第一次打开时没有任何操作说明。
- 390 的 HUD 是压扁的桌面版：顶栏 113 + 底栏 266 = **379px = 44.9% 屏高**，天幕只剩 465px；品牌两行 111×46；「情感/体裁」被挤成 46×42 的两行字；`#side` 16×552，从 y=146 一直压到 y=698，**插进底栏 120px**；「检索/着色」标签竖排两字。
- 检索只有数字没有结果：输入「明月」→ `qc=7`；回车直接打开得分最高的《八哀诗 赠太子师汝阳郡王琎》，用户无法在 7 首里挑。而这 7 首的标题一个都看不见。
- 最后是比例：**24,000 个白噪音点 vs 1,468 首真诗（16.3:1）**，伪诗默认开。我随手点两处（14:46 桌面空白、15:05 手机 (60,200)），两次都开成白噪音（标题分别是「评丁」「索相明府」）。新用户第一次点星，大概率得到的是一首读不出意义的假诗。

## 另外三条（次伤，但都不该留到下一轮）

**A. 手机 HUD 还是桌面版压扁的，触摸目标普遍 16–28px。** 390 下底栏 266px、顶栏 113px，天幕只剩 465px；`#side` 552px 高压进底栏；chips 46×42 两字一行；`#hint` 被 `max-width:1500px` 规则直接 `display:none`。触摸区：`#readtoggle` 48×24、`#csound` 68×24、`#close` 26×26、`.rel i` 49×24、`.kw span` 51×26、`#c-poemhint` 28px 高、图例 69×16。手机刚成为正式场景，至少把主按钮和提示做到 44×44。另外卡片的 `.ft` 在 ≤1000px 是 `max-height:32vh; overflow-y:auto`：390 下「关系」标签在 y=762 还能看见，`.kw` 的 `灯/矣/雨/白` 已经到了 y=880（屏外），卡片本身不滚，只有底栏在内部滚，用户很难发现最后一排。

**B. 键盘与读屏仍是零。** 卡片关闭时 Tab 仍落到屏外的 `#csound`（x=2177）和 `#c-poem`（x=1926）；`#readtoggle` / `#close` 是不可聚焦的 div；`<button>` 0 个、`aria-live` 0 个、`h1` 0 个；`prefers-reduced-motion` 0 条。最低限度：两个 toggle 换成 `<button>`，卡片关闭时 `#card{inert}`，`#qc` 加 `aria-live="polite"`，reduce 下关 `autoSpin` 与逐字入场。

**C. 手机卡片底栏是嵌套滚动，最后一排常被切。** 与 A 同源：`.ft` 内部滚动，`#c-kw` 在 844 之外；没有滚动阴影/渐隐提示。建议 ≤700px 让整张卡 `overflow-y:auto` 一滚到底，或者给 `.ft` 底部加 12px 渐隐。

**为什么是 +7 而不是更多**：触屏第二点、白噪音、390 单栏与 Esc 两步是四处「用户真的会撞上」的坏点，这轮都修干净了，值得 +7。不给更高，是因为「找到」连续四轮没动：0 个诗题、1.83:1 的输入框、1366/手机连操作提示都没有；而这轮把「全屏读」做得更顺，入口却仍然是一个几乎看不见的输入框。**产品不是「能打开一次」，是「第一次就知道点哪儿，第二次还能打开另一首」。** 第二句这轮做到了，第一句还没有。

## 一句总评

这版最像作品的一屏仍是天幕，最像产品的一步是手机全屏终于能读了；但首屏还是一张没有标题的星图，24,000 颗假星围着 1,468 首真诗，而唯一的入口是一条 1.83:1 的虚线。**先把 6 个诗题、两处对比度和那行提示放回来，再谈金色滚动条和进度**——这三件都是几十行的事，却决定新用户能不能找到第一首诗。
