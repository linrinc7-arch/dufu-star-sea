# 第 23 轮 · 2026-10-20 15:10

## 用户问：这是啥

那一版是「星云把星空吃掉了」：我把星云亮度乘了 1.35、幂次收到 1.95，
结果整片天变成一块紫灰色的雾，1468 颗诗星全被压在下面，几乎看不见。
再加上底部的地面渐变，看上去就是一片意义不明的雾 + 一条黑边。

## 修正

| 项 | 上一版 | 现在 |
|---|---|---|
| 星云亮度 | pow(cloud,1.95)×1.35 | pow(cloud,2.15)×0.52 |
| 暖核权重 | n^3.4 | n^4.2（核心更集中，外围更空） |
| 底雾 | band×3/4/7 | band×2/2/4 |
| 诗星体量 | r×2.25 | r×2.75（上限 40px） |
| 诗星亮度 | 0.42+1.05·mag | 0.62+1.20·mag |
| 泛光 | 0.38 | 0.26 |

原则一句话：**星云是背景，星星是主角。背景亮了，主角就没了。**
