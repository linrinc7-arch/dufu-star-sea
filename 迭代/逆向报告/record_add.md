## 14. 第四轮：天幕重写（2026-10-20 21:20）

### 起因
用户点名参考 https://shiyun.cohenjikan.com （刘慈欣《诗云》的三维星图）的星空，用 REA 逆向后改进本作。
逆向报告在 work/rea/shiyun/reports/（架构 / 数据 / 渲染 / 迁移四份，共 3,000+ 行）。

### 诊断（旧天幕的三处硬伤）
1. **1,468 首诗用轨道相机投影**（project()，cam.dist=2.9），诗的半径是 1 → 整片星海缩在屏幕中央约 914×914 px 的圆盘里，边缘因切向投影堆成一圈。用户说的“球状尘埃”就是这个。
2. 天幕是 **512×256 fbm 烘的 2048×1024 贴图**，放大即棉花，上下黑边来自 pitch 钳位。
3. 亮度靠尺寸不靠叠加；没有真实星表、没有星等长尾、没有色温。

### 改动
| 项 | 旧 | 新 |
|---|---|---|
| 投影 | 轨道相机 | 球心 gnomonic（projectSky，本来就有，从没被调用） |
| 银河 | 随手写的极点 + fbm | 真实银河北极（RA 192.859°, Dec +27.128°）+ 5 级等照度轮廓 |
| 背景星 | 9,000 个 64px 精灵 | 52,000 个 1px 向量点（按气体亮度加权） |
| 恒星 | 无 | 5,044 颗真实星表（星等 + B-V 色温） |
| 诗星 | 彩色精灵 | 白热核心 + 彩色外晕；尺寸 ×(0.85+0.30·zoom) |
| 银心 | 无 | 方向正确的暖色辉光 |
| 性能 | 每帧全量重画 | 天球层缓存（0.35 px 阈值）；帧率 6.4 → 15.4 fps（同机 A/B） |
