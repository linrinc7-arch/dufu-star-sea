## 3. 天幕：球心视角下的真实天球（第四轮改写）

天幕不是图片，也不是一张贴图：它是一座球心视角的天球。人站在球心，星是点，气体是烘出来的底图。

| 层 | 做法 |
|---|---|
| 银河 | 真实五级等照度轮廓（2,375 点）填进等距圆柱画布 → 轻度模糊 → 两层噪声切暗带 + 两层高频做卷须 |
| 色彩 | 按银心方向加权：银心一侧暖金，外圈冷蓝；脊线上一点洋红 |
| 背景星 | **52,000 颗向量点**，密度按气体亮度加权（银河流到哪，星就密到哪） |
| 恒星 | **5,044 颗真实星表**（mag ≤ 6）：星等定大小、B-V 色指数定颜色，亮星补光晕 |
| 星座 | 88 条星座连线，透明度 0.085 —— 只在远处当“星图”的暗示，不许抢主体 |
| 银心 | 一团方向正确的暖色辉光，给画面一个焦点 |
| 诗 | 1,468 首贴在**真实银道带**上（银心方向密度更高），白热核心 + 彩色外晕 |
| 白噪音 | 9,000 粒极暗的伪诗点，同样的银道带分布 |

**规矩**：
1. 不许用照片、不许用生成的图片当背景；天幕必须能在断网的浏览器里由代码跑出来。
2. **星的形靠点，不靠贴图**：气体可以软，星必须一直是 1 px 的点——这是放大后不糊的唯一办法。
3. 天球层做缓存：相机位移小于 0.35 px 时整层不重画。

**数据来源**：d3-celestial（HYG 星表派生，CC-BY-SA），构建期由 work/rea/shiyun/stars/build_sky_data.py 压成 121 KB 的 web/sky_data.js。
