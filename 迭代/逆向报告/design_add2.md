
### 3.1 星海（默认视角）：照着参考站铺的星系

1,468 首诗不是散在天上，而是**一个四臂旋涡星系**。构造完全来自对 shiyun.cohenjikan.com 的逆向：

| 步骤 | 做法 | 对应源码 |
|---|---|---|
| 随机源 | FNV-1a(标题 + # + 编号) → 32 位，坐标全从位段里取，**没有坐标表** | pretty/index.js:3284 |
| 半径 | 五期 → 半径带 0.11~0.97，**越靠外越晚**（参考站是朝代 → 半径） | :3276-3283 |
| 角向 | 4 臂 + 半径 × 5.2 rad 扭转 + 臂宽抖动；内盘整圈打散 | :3785-3798 |
| 厚度 | 盘厚 = 半径的 11%，核球再鼓 ×2.6 | 同上 |
| 散布 | 三角噪声 a+b+c-1.5（不是高斯） | :3793 |
| 背景 | 80,000 个加色点，同一套臂；按半径分 5 段色（暖金 → 赭 → 青灰） | :3904-3923 |
| 核 | 一团暖色径向辉光 | :3959 |

**规矩**：点数永远大于画布像素能分辨的数量，靠叠加出亮度；颜色只由半径（时间）决定，
不在同一处混色；泛光必须把亮部糊开。

右上角「天球 ›」按钮切到真实天球视角（真实星表 + 银河轮廓），「星海 ›」切回来。
