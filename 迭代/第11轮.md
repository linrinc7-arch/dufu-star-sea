# 第 11 轮 · 2026-10-20 09:50

## 本轮做了什么：把"球外看"改成"站在球心看"

用户提出："模仿真实星空，杜甫的第一首诗作为宇宙中心，从中心往四周看，星星的连线做成星座。"

这是结构性改动，不是调参：

### 1. 天球投影
原来相机在球外绕着一个球看（orthographic-ish），现在改成**相机站在球心向外看**：

- 取《望岳》作为原点（杜甫现存最早的作品之一）
- 每首诗相对原点的向量归一化为**方向**，全体铺成一个天球
- 投影改为标准透视：`sx = CX + (x/z)·f`，视线背后（z≤0.06）剔除
- 拖拽 = 转头，滚轮 = 改焦距（FOV），不再是"绕球旋转"

### 2. 距离编码
语义上"离《望岳》多远"映射为**亮度与体量**：`a ∝ 0.95+0.55(1-nd)`、`size ∝ (1-0.34·nd)`。
离起点越近的诗，星越亮越大。

### 3. 星座只连看得见的星
连线的最小生成树只接受当前视野内的候选（`if(!pm._q) continue`），
所以星座是"你此刻能看见的那一片天空里的形状"，而不是一张隐形的图。

### 4. 视角可切回
底部加了「视角 天球 / 星云」开关，旧的外视角保留。

## 修掉的两个 bug
| bug | 现象 | 原因 |
|---|---|---|
| 选中后整屏全黑 | 一按就黑 | 天球下被剔除的星点 `_q` 为 null，连线代码直接读 `.sx` 抛错 |
| 连线原点错位 | 星座从错误位置发出 | 原点仍在用旧的球外投影 `project()` |

## 观察
改成天球后，星点的分布从"一坨"变成"满天"，
因为归一化方向把三维聚类摊平到了球面上——**密度结构被角度化保留了**（有的方向密、有的方向空），
这比原来的球外视角更像真实星空。
