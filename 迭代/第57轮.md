# 第 57 轮 · 2026-10-20 21:30 · 声音铺开与生涯巡游

## 1. 声音从「两三个点」铺到整站

评审连着两轮说「真诗只有一记 196Hz，悬停/检索/时期/图例十余类交互全静音」。
这一轮加了统一的 `audCue(kind)`：

| 类 | 声音 | 电平 |
|---|---|---|
| hover | 1568Hz 极短正弦（110ms 节流） | 峰 −31dB |
| type | 880Hz 方波 50ms | 峰 −34dB |
| zoom | 900Hz 带通噪声 220ms | 峰 −30dB |
| filter / legend | 196Hz 低木 | 峰 −28dB |
| panel | 110Hz 闷响 | 峰 −28dB |

全部比选诗音低 10dB 以上——界面音存在，但不抢诗。

另外三条：
- **随机钟改走卷积混响**（之前直连 master，评审说「钟仍不进混响」）
- **真诗按题目哈希取五声音阶度数**：196Hz × 2^(五声/12)，同类同调、异类不同高，不再一千四百首一个音
- **底噪再抬中频**：低通 620Hz、第三分音 330Hz，呼吸同时改音量与截止频率

## 2. 新功能：生涯巡游

页脚新增「生涯 · 巡游」：五期依次点亮，每期 5.2 秒，配一声磬与一行字幕
（例如「困守长安 746—755 · 196 首」）。按 `t` 键也能起停。
这是把「生平」从一张静态年表变成一次可以看的时间旅行——
天幕会随时期改换高亮的那一千多颗星。
