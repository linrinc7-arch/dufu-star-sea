## 本轮做了什么

### B4 页面级转场（上轮最弱项，3.5 分）
- 面板揭示方向由"自下而上"改为**横向擦除**：`clip-path: inset(0 0 0 100%)` → `inset(0 0 0 0)`，0.9s，曲线 `cubic-bezier(.76,0,.24,1)`（先快后慢，像纸被抽走）
- 揭示边缘加一道**金色扫线** `#sweep`：1px 渐变竖线，随擦除轨迹从右到左掠过，8% 处淡入、92% 后淡出
- 关闭时反向：扫线从左回右，面板反向擦除
- 内容错峰改为按 DOM 顺序 70ms 递进，延迟从 180ms 起，让"揭开"之后内容才陆续落位

### 截图证据链修复
交游网络的入场动画（`animation-delay` 最长 860ms）在截图时点尚未完成，导致节点全透明。
在 capture 的 NOANIM 里补 `.fnet line,.fnet .fnode{opacity:1!important;animation:none!important}`，证据图恢复可读。
