# 第98轮：星点加亮 · 出生在星海内 · 遨游视野限制（2026-10-21）

## 起因（用户原话）

> 星星太小太淡了，然后出生摄像机改成在星海内，闪烁回退出来，然后wasd的时候鼠标稍微移动就看不到东西了，
> 建议加个视野限制1，让视野内的星星变少。

## 先说一件事：上一轮改到一半就断了

用户贴来的 413（payload 17.5MB > 16MB）把上一轮掐死在半路。核对后发现：

- web/index.html **已经**有「星点变大变亮 / 出生在星海内 + 闪白 / 飞行时背景点减半 / 灵敏度 0.0042→0.0022」的改动；
- 但 杜诗星海.html 与 交付/杜诗星海.html 还停在 14:08 的旧构建（md5 与重新构建的结果不一致，差异 130 行）。

也就是说：**用户看到的还是旧版**，改的东西从没进过构建。本轮先把这条链补上，再做缺的那部分。

## 改了什么

| 用户说的 | 做法 | 落点 |
|---|---|---|
| 星星太小 | 诗星体量 1.55→1.72（上限 14→16px，飞行 34→36）；背景点 4.3/d→4.7/d，上限 2.4→2.7px | render() 诗星分支、drawGalaxyPoints() |
| 星星太淡 | 背景星 8 档透明度整体 +0.03~0.04（0.14…0.84 → 0.17…0.85）；辉光门槛 3.6→3.3、强度 .24→.27 | GAL_ALPHA、辉光层 |
| 出生在星海内，闪一下再退出 | 出生距离 0.92→**0.72**（更靠里），620ms 时闪白，4.2s 平滑退到 3.9；开机常量同步 | INTRO.from、bootReady() 里的 cam.dist |
| 鼠标一动就什么都看不见 | **视野限制**：按“相机到银心距离”算允许偏轴角，越远越紧（4.1 单位 ≈20°）、钻进星海再放宽（≈46°）；超界沿大圆压回，并把拖拽基准收回当前朝向 | 新函数 roamViewLimit() / roamClampView() |
| 视野里的星星少一点 | 飞行时背景点抽样 ×2，钻进 1.7 以内再降一档 ×3 | drawGalaxyBack() 的 stride |

视野限制同时挂在三条路径上：锁鼠转头、拖拽环视、updateRoam() 每帧兜底（位置一变，允许角跟着变）。
