# 第 44 轮 · 2026-10-20 16:10 · 银河 = 一条乳白亮带

## 我错在哪

用户说「去搜银河系构成」。查下来最朴素的一句：银河是**横跨星空的一条乳白色亮带**——
那是在银河系**里面**往外看的样子。我前面做的是「从外面看一枚星系」（俯视螺旋、侧视盘），
那是仙女座大星云的样子，不是我们头顶的银河。所以怎么做都不对。

## 这一版按「站在里面」做

| 结构 | 做法 |
|---|---|
| 亮带 | 78% 的诗落在银道面 ±20°—35° 内（高斯），带宽在银心附近更厚 |
| 银心 | 10% 的诗聚成一个半径约 17° 的球核，另 22% 的白噪音堆在同一个方向当光 |
| 暗尘 | 带内用噪声挖出整段的空——「大裂缝」，不是撒点稀疏 |
| 带外 | 12% 的诗散在全天，任何角度都不是空的 |
| 白噪音 | 26,000 粒，同样是带 + 核，暖色集中在银道面内 |

## 相机

默认朝银心方向、沿银道面看：亮带斜贯画面，银心在右上。转头时带子跟着转，
仰头看银极时它会变成环绕地平的一圈——这是真实的观测行为，不是 bug。
