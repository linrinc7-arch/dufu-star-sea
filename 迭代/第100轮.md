# 第100轮：臂间会闪的星 + 参考实现（2026-10-21）

## 用户说的

> 悬臂之间应该也有星星闪烁的，之前我就提到过这一点，为什么不做呢。可以上 github 搜一下类似的开源项目。

## 为什么之前没做

第 6 轮确实补过「臂间空洞」：2 万颗白噪音伪诗填进臂间。但它们被画进**星系缓存层**——
缓存一帧只画一次，相机不动就不重画，所以那层星是**静态**的，永远不会闪。
这轮把它们之外再加一层不进缓存的「臂间场星」，逐帧算闪烁。

## 参考的开源实现（GitHub）

| 仓库 | 拿到的做法 |
|---|---|
| [Danziger/starsjs](https://github.com/Danziger/starsjs) | canvas 星系；每颗星带自己的强度，按概率随机游走 (`INTENSITY_CHANGE_PER_FRAME=0.05`)，亮星光晕用缓存的 radial 贴图 |
| [at9omr/Cosmic-Spiral-Galaxy](https://github.com/at9omr/Cosmic-Spiral-Galaxy) | Three.js，3 万粒子；旋臂 + 场星两个 population |
| [paragraff/star-map](https://github.com/paragraff/star-map) | Google「100,000 Stars」的 WebGL 复刻：点的尺寸/亮度全在着色器里按相位算 |
| [teddarcuri/Starfield](https://github.com/teddarcuri/Starfield) | CSS 动画流：每颗星一个 animation-duration/delay，天然不同步 |

共同点：**闪烁是逐点相位算的，不是整层统一呼吸**。本作照这个做。

## 实现

- 新 `buildSparks()`：4,200 颗「场星」，角度取相邻两条旋臂的中线再按半径抖动，半径 0.10~1.42，带各自的相位与频率（0.8~3.4 rad/s）。
- 新 `drawSparks(t)`：**不进缓存**，每帧在主画布上画。闪烁用两个八度叠加（`sin(ωt+φ)` 与 `sin(2.7ωt+1.9φ)`），
  取平方让「大部分时间暗、偶尔亮一下」；亮到峰值时叠一层小光晕。
- 层级：星系缓存 → 臂间闪烁星 → 诗星 → 后处理。
- 成本：4,200 次 fillRect/帧，软件光栅约 3ms。
